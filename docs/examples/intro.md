# Example Projects

In this section, we will look at a two more examples of languages ​​implemented using PyLGEN, where we will see its capabilities in practice and learn how to address some common issues.

## Examples

> ### [`idented_dsl`](idented_dsl/idented_dsl.md)

An interpreter for an indentation-sensitive configuration language.

> ### `mini-python`

A complete interpreter with GUI included to handle a subset of the Python language.
